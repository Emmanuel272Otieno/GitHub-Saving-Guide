Eight Steps to Save Your Work

Read each step and mark it complete when you finish.

Your learning progress 0 of 8 completed
01

Install Git

Check whether Git is installed on your computer.

git --version

If Git is missing, install it from git-scm.com.

02

Initialize a Repository

Open your project folder in the VS Code terminal.

git init

This creates a local Git repository.

03

Add Your Files

Stage your project files so Git can include them in a commit.

git add .

Use git add filename for one file.

04

Commit Changes

Save a snapshot of your staged changes locally.

git commit -m "Initial commit"

Write a clear message describing your changes.

05

Create a GitHub Repository

Sign in to GitHub, create a new repository, and copy its URL.

Create a repository ↗

For this workflow, create an empty repository without a README.

06

Link the Remote Repository

Replace the example URL with your own GitHub repository URL.

git remote add origin https://github.com/USERNAME/REPOSITORY.git
07

Push Changes

Set your branch to main and upload your committed work.

git branch -M main
git push -u origin main

Sign in to GitHub when prompted. You need permission to push.

08

Verify on GitHub

Open your repository page and check that your files appear.

Open GitHub ↗

Check the repository name and uploaded files.

Saving Future Changes

Whenever you edit your project, use this workflow:

git add .
git commit -m "Describe your changes"
git push

💡 Important Tips

  • Always open the terminal in the correct project folder.
  • Use meaningful commit messages.
  • Never upload passwords, API keys, or private information.
  • If Git says a remote named origin already exists, check it with git remote -v.
  • If you receive a permission error, check that you are using the correct GitHub account.
